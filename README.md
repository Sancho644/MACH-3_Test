# MACH-3_Test

`MACH-3_Test` - учебный Unity-проект в жанре Match-3. Игрок взаимодействует с игровым полем, собирает комбинации из одинаковых фишек, получает очки и может попасть в таблицу рекордов.

## Описание программы

Программа включает:

- главное меню;
- игровую сцену с полем Match-3;
- экран рекордов;
- экран `About`;
- окна возврата в меню и завершения партии.

Проект реализует базовую игровую логику Match-3: проверку допустимых ходов, подсчёт очков, начисление бонусных ходов за комбинации и отображение подсказок.

## Краткое руководство к игре

Цель игрока - набирать очки, собирая на поле комбинации из трёх и более одинаковых фишек.

### Управление

- нажмите и перетащите фишку в сторону соседней клетки, чтобы поменять их местами;
- если после обмена образуется комбинация, совпавшие фишки исчезнут, а сверху появятся новые;
- если просто нажать на фишку без перетаскивания, активируется одиночный взрыв клетки;
- при наличии подходящего хода игра может показать подсказку.

### Игровой процесс

- каждый ход расходует доступное количество ходов;
- за собранные комбинации начисляются очки;
- за более крупные совпадения выдаются дополнительные бонусы;
- после каскадных совпадений поле автоматически перестраивается;
- когда ходы заканчиваются, игра завершает партию.

### Завершение игры

- если результат достаточно высокий, он попадает в таблицу рекордов;
- если очков недостаточно для рекорда, открывается окно завершения игры с возможностью вернуться в главное меню.

## Навигация

Из главного меню можно:

- начать новую игру;
- открыть таблицу рекордов;
- перейти на экран `About`;
- выйти из приложения.
